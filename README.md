# AMR Atlas

Frontend-first прототип платформы мониторинга антимикробной резистентности.

## Публичный визуальный preview

**GitHub Pages:** https://mg-trener.github.io/ATLAS/

В корне репозитория находится standalone-preview (`index.html` + `preview.css`). Он нужен для быстрого визуального контроля без БД, backend и локального запуска. После изменений в `main` GitHub Pages автоматически обновляет публичную версию.

Параллельно развивается основной Next.js frontend в каталоге `app/`.

## Текущий этап

Проект работает **без базы данных и backend**. Все показатели на dashboard являются демонстрационными mock-данными. UI специально отделён от будущего источника данных, чтобы позже подключить импорт WHONET/API без переделки экранов.

## Стек

- Next.js 16
- React 19
- TypeScript
- Lucide icons
- CSS design system без UI-фреймворка
- GitHub Pages для визуального preview

## Локальный запуск

```bash
npm install
npm run dev
```

Открыть: `http://localhost:3000`

## Принцип данных

Сейчас:

`UI → mock data`

Позже:

`UI → data provider → API → WHONET importer → PostgreSQL`

## Следующие этапы

1. Сделать отдельные полноценные экраны «Микроорганизмы», «Антибиотики», «Карта», «Аналитика» и «Сигналы».
2. Разнести dashboard на переиспользуемые компоненты.
3. Подготовить единый mock-data provider, чтобы все экраны использовали одну модель данных.
4. Подготовить интерфейс загрузки WHONET-файлов без фактической записи в БД.
5. После согласования модели данных подключить backend и PostgreSQL.

> До подключения реальных источников любые числовые показатели на экране являются демонстрационными.
