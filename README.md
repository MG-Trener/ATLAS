# AMR Atlas

Прототип будущей платформы мониторинга антимикробной резистентности в Казахстане.

## Публичный визуальный preview

**GitHub Pages:** https://mg-trener.github.io/ATLAS/

В корне репозитория находится standalone-preview для быстрого визуального и функционального контроля без локального запуска. Публичный прототип развивается параллельно с основным Next.js frontend в каталоге `app/`.

## Карта и региональные профили (20.09.2026)

Главная `index.html` открывает обновлённую карту Казахстана. Выбор любой из 20 территорий открывает её карту и профиль с общей системой фильтров, R/S/I, N, 95% ДИ, динамикой, таблицами и CSV. Кнопка возврата и история браузера работают; регион можно открыть прямой ссылкой `index.html?region=KZ35`.

Все показатели нового экрана синтетические, модель `atlas-model.mjs`. Публичные строки с N < 30 подавляются по правилу проекта. Правовые основания и оставшиеся условия подключения реальных данных: [обзор публикации](docs/KAZAKHSTAN_PUBLICATION_REVIEW.md).

Прежняя лабораторная концепция сохранена в `clinical-preview.html`. Другие концепции и Next.js не переведены на новую модель; их старые демонстрационные цифры не следует сопоставлять с новой витриной.

## Текущий этап

Проект находится на стадии функционального прототипа.

Уже подключена **Supabase** для справочного и knowledge-слоя:

- полный versioned snapshot WHONET / AMRIE для микроорганизмов и антимикробных препаратов;
- расширенные RU / KZ / EN карточки приоритетных организмов и препаратов;
- справочник механизмов AMR и связей «механизм ↔ организм ↔ препарат»;
- RLS и публичный read-only доступ к безопасным справочным представлениям;
- подготовлено ядро будущих surveillance-таблиц для импортов, изолятов, AST и контроля качества.

**Реальные surveillance-наблюдения пока не загружены.** Все числовые показатели резистентности, MDR, сигналов и региональных трендов в аналитических экранах являются демонстрационными и не являются официальной статистикой Казахстана.

## Публичные концепции интерфейса

Прототип позволяет сравнить три модели будущей платформы:

1. **Clinical Workspace** — рабочее место лабораторного/AMR-аналитика.
2. **National AMR Atlas** — публичный картографический национальный обзор.
3. **AMR Intelligence Center** — ситуационный режим мониторинга и расследования сигналов.

Выбранная концепция и язык сохраняются в браузере. Поддерживаются RU / KZ / EN.

## Принцип данных

Сейчас:

`UI → shared demo AMR provider`

`UI → Supabase reference / AMR knowledge views`

Будущая целевая цепочка:

`WHONET / LIS → import batch → validation → isolates → AST → deduplication → quality control → aggregates → map / analytics / AMR Radar`

## Важное ограничение прототипа

До загрузки и методологической валидации реальных источников любые числовые AMR-показатели на аналитических экранах должны трактоваться только как демонстрационные.

Перед пилотной эксплуатацией необходимо выбрать единый production frontend, перенести standalone-прототип в компонентную архитектуру, добавить автоматические тесты/CI и формализовать методологию расчёта показателей.
