# AMR Atlas

Frontend-first прототип платформы мониторинга антимикробной резистентности.

## Текущий этап

Сейчас проект работает **без базы данных и backend**. Все показатели на dashboard являются демонстрационными mock-данными. UI специально отделён от будущего источника данных, чтобы позже подключить импорт WHONET/API без переделки экранов.

## Стек

- Next.js 16
- React 19
- TypeScript
- Lucide icons
- CSS design system без UI-фреймворка

## Запуск

```bash
npm install
npm run dev
```

Открыть: `http://localhost:3000`

## Что уже есть

- широкоформатный AMR dashboard;
- навигация и верхняя панель;
- фильтры по микроорганизму, материалу, региону и периоду;
- KPI-карточки;
- таблица резистентности по антибиотикам;
- схематичная карта Казахстана;
- график динамики резистентности;
- сигналы и оповещения;
- тепловая карта «регионы × антибиотики»;
- блок качества данных;
- адаптация под меньшие экраны.

## Следующие этапы

1. Разнести dashboard на переиспользуемые компоненты и страницы.
2. Добавить разделы «Микроорганизмы», «Антибиотики», «Карта», «Аналитика» и «Сигналы».
3. Подготовить слой `data/` и интерфейсы для будущего API.
4. Подключить импорт WHONET.
5. Подключить PostgreSQL/backend после согласования модели данных.

> До подключения реальных источников любые числовые показатели на экране являются демонстрационными.
