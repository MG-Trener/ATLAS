Последние доступные данные AMR по миру

Карта использует основной массив WHO GLASS Dashboard через официальный WHO XMART API. По умолчанию для каждой страны берётся её последний опубликованный год по выбранной комбинации: контекст инфекции/материала → микроорганизм → антибиотик.

Серый цвет — не «нет резистентности»

Серым показаны страны, для которых WHO GLASS не публикует значение по выбранной комбинации. Доступность зависит от года, вида инфекции/материала, микроорганизма и антибиотика. Для сравнения стран рекомендуем режим «Последние доступные по каждой стране».

Автоматическое обновление и последняя доступная запись

Раз в неделю. GitHub Actions запрашивает официальный WHO XMART `RELAY_GLASS_AMR`, валидирует структуру и сохраняет новый snapshot только после успешной проверки. Версия и дата синхронизации видны выше.
Latest available. В этом режиме карта не заставляет все страны иметь один и тот же год: для каждой страны выбирается её самый свежий опубликованный WHO GLASS результат по текущей комбинации.
